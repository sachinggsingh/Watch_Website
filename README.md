#  Zoop Watches

Welcome to the **Zoop Watches** repository! This project showcases a modern and responsive website for displaying a collection of premium watches. It is designed to be visually appealing, user-friendly, and highly customizable.

---

## Features

- **Responsive Design**: Fully compatible with devices of all screen sizes.
- **Dynamic Content**: Display a variety of watch collections with smooth transitions and animations.
- **Modern UI/UX**: Sleek and clean interface with intuitive navigation.
- **Customizable Components**: Easily update and extend the website content.

---

## Tech Stack

The project is built using the following technologies:

- **HTML5**: For the website structure.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactivity and animations.
- **Bootstrap**: For responsive design and components.
- **Tailwind CSS**: For advanced styling.

---

## Installation

Follow these steps to set up the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sachinggsingh/Watch_Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Watch_Website
   ```

3. Open the `index.html` file in your browser to view the website.
